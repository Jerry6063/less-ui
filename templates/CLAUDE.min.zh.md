# 界面规则

评委只看 60 秒。像设计的，不像生成的。越少越专业。

1. 先定方案再写 CSS：用户和他唯一的任务；密度跟任务走；4-6 个 hex 色，一个强调色；不用 Inter/Roboto/Arial/system-ui；一句版式，一条原则。换个题目也成立的行就是默认，重写。
2. token 先行：第一个 CSS 块是 :root，含调色板、--t-display/heading/body/meta、--r-1/2/3、--s-1/2/3、--shadow-rest/lift。尺寸全引用 token，:root 外只许 0。
3. 层级靠对比：焦点 ≥ 标签 3 倍；一屏最多 4 个字号；一个指标压其余，禁止六格等大。
4. 禁用：米白 #F0EDE4-#FAF7F0 配赭石 #A84A14-#E08A5A、渐变、同款圆角卡片、全大写小标、按钮尾箭头、emoji 图标、逐区块入场动画、「仪表盘就深色」。主题按场景选并说明理由。
5. 精炼：元素不服务决定就删；摘要优于原始数据；一屏一图；区块标题说含义不说名称；交付时点名砍了什么。
6. 状态：骨架屏、空态一句话加一个动作、错误给原因和下一步。控件不改变视图就删。标签与数据一致，14 天就 14 个点。环比合理，峰值标原因。演示开关单独成条。
7. 表格：状态列 1440 下完整可见，不横滚；行高 48-60，次级信息内联；语义色只用于点、标签、增减值；sticky 带 background 和 z-index。
8. 流程：一屏一问；步骤条只显示进度；约束写成焦虑点旁的文案；主按钮未就绪即禁用；一句副标题讲清流程；输入框预填示例；手机框 375x812，点击真跳转。
9. 底线：真实内容、可见焦点、button/a 语义、图标按钮 aria-label、对比度 4.5:1、移动端正文 16px、100dvh、tabular-nums、只动 transform/opacity 且 200ms 内、尊重 reduced-motion。
10. 自检一遍改一次即交付。单个 index.html 内联 CSS/JS，file:// 可开。说明：方向与主题理由、砍了什么、三件待验证。

## 只剩一分钟

- 先定用户任务、调色板 hex、字号阶梯，全部进 :root，外面不许字面尺寸。
- 焦点 ≥ 标签 3 倍，一屏 4 个字号，一个指标压其余；禁米白配赭石、渐变、卡片堆、全大写小标、按钮箭头、emoji 图标。
- 骨架屏、空态一动作、错误给原因；控件不改视图就删；元素不服务决定就删；自检一遍即交付。
